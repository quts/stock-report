## 授權範圍與義務

[政府資料開放授權條款第1版](https://data.gov.tw/license) 的第二節允許重製、散布與改作等利用；第三節要求依附件明確標示來源。授權不代表政府推薦研究方向，也不授與商標或專利權。報告需具資料提供機關、資料集名稱／版本、年份及授權連結，不應只寫泛稱「官方資料」。

## 目前限制

這份查核補上具體資料集證據，不能冒充人工簽認。現行 AGENTS.md 要求真實研究使用「已人工查證身份、時點與權限」的證據；在依該契約完成查核及確認端點對應前，不把真實來源直接改為可內部使用。報告自 2026-11-15 起僅供個人使用、不分享，但這不改變上述人工簽認要求。來源網站的一般禁止重製條款與政府開放資料的個別授權必須按資料集分開判斷。

這些資料集可提供收盤交易紀錄，不足以單獨驗證 3–12 個月研究方向，也不證明存在財報、歷史調整價格、機構評等或重大事件證據。
