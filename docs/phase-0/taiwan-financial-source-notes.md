## 來源宣告了什麼、沒宣告什麼

| 問題 | 來源是否宣告 | 本專案處理 |
| --- | --- | --- |
| 期間起訖日 | 否，只有年度與季別 | 起訖由年度／季別加上 `config/tw-instruments.json` 明示的 `fiscal_year_end_month` 推得；沒有該設定即拒絕，不預設曆年制 |
| 累計或單季 | 否 | 實測交叉核對為**年初至今累計**（見下）；以 `period_basis=cumulative_ytd` 保存，Q4 也不改標為年度或 TTM |
| 金額單位／級距 | 否（只有 EPS 欄位名稱帶「（元）」） | 金額保留來源原值，單位標為 `source_scale_undeclared`，`source_unit_raw` 留空；只用於同一申報紀錄內的比率 |
| 公司申報／公告時間 | 否，只有出表日期 | 出表日期原樣保留於 `source_published_raw`，公開時間採 `observed_availability`；不支援早於擷取時點的歷史截止 |
| 前期比較數 | 否，只有最新一期 | 不產生 `revenue_prior`／`eps_prior` |
| 會計年度、財報格式（一般業／金融業…） | 否（格式隱含在資料集） | 由標的設定明示，並拒絕非 `general` 格式 |

### 累計基礎的交叉核對

資料集沒有說明數值基礎，因此以另一份官方申報交叉核對：每月營業收入彙總表
（`t187ap05_L`／`mopsfin_t187ap05_O`）明確有「累計營業收入」欄位。將其累計數回推到季末月份後，與損益表的
`營業收入` 相除，只輸出比值：

| 標的 | 損益表期別 | 月營收期別 | 比值 | 若為單季應約為 |
| --- | --- | --- | --- | --- |
| 2330 | 115Q3 | 11510 | 1.000 | 0.333 |
| 6488 | 115Q3 | 11510 | 1.000 | 0.333 |

結論限於這兩個標的、這一期：損益表營收是年初至今累計，且與月營收申報同一級距。`smoke` 與網路契約測試每次執行都會
重做這個核對（`cumulative_basis_check`），只落盤比值與結論。季末月份與月營收期別相差超過兩個月時無法回推，會標為
`not_checkable_for_this_period`，不視為通過。這不是官方條文，也沒有確立金額級距的絕對單位。

## 因此省略的指標

| 指標 | 狀態 | 原因 |
| --- | --- | --- |
| net_margin | 可計算（授權確認後） | 同一申報紀錄、同一期間起訖、同一未宣告級距，比率不受級距影響 |
| revenue_growth、eps_growth | 省略 | 端點只有最新一期累計數，沒有可比的前期同窗資料 |
| pe | 省略 | 累計基本 EPS 不年化、不冒充 TTM；即使收盤價與 EPS 都存在也拒絕 |
| free_cash_flow | 省略 | 此資料集不含現金流量表 |
| 任何絕對金額的跨來源比較 | 省略 | 金額級距未由來源宣告 |

未宣告級距的兩個數值只有在同一發布者、同一來源 URL、同一來源紀錄 ID 且同一次擷取時才可相除；不同申報紀錄或不同次擷取即使單位標記相同也拒絕計算。

確定性計算另外加上期間視窗規則：官方財務證據必須帶期間起訖與基礎；同期比率要求起訖完全相同；年增率要求兩期皆為
`fiscal_year` 且前期結束日的次日即本期起始日。期別標籤或結束年度相同（或相鄰）不足以視為可比。SEC adapter 的前期判定
同步由「結束年度相差一」改為「期間相鄰」。
