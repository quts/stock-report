## 本次查核：2330 身份與最近收盤

查核者：Codex AI；查核日期 2026-11-15（Asia/Taipei）。沒有冒稱人工查核。

- **免費與權限**：[政府資料集 11549](https://data.gov.tw/dataset/11549) 明列計費方式「免費」、授權方式「政府資料開放授權條款-第1版」、每日更新，並列出日期、證券代號、證券名稱及收盤價欄位。
- **使用條件**：[官方條款](https://data.gov.tw/license) 第二節允許免授權金的重製、編輯等利用，第三節及附件要求顯名；不需要另取得書面授權。本專案採正規化數據的本機保存及個人 PDF，保留提供機關、年份、資料集與條款連結；不開啟分享、原始回應或回應雜湊保存。
- **端點對應**：資料集備註直接連到 [TWSE OpenAPI 文件](https://openapi.twse.com.tw/v1/swagger.json)。本輪在 Apple Container 重新比對指定 CSV 與 STOCK_DAY_ALL JSON，2330 唯一命中，名稱、收盤及日期皆相符；Swagger 列出該端點。只保存查核布林結果，見 `ai-twse-binding.json`，不將整個交易所其他 API 視為一併獲准。
- **公司與股類**：[台積電官方 FAQ](https://investor.tsmc.com/english/faq) 確認 TWSE 2330；[官方 2025 Form 20-F](https://investor.tsmc.com/sites/ir/sec-filings/2025_20F%20Report.pdf) PDF 第 63 頁 Item 9 明載上市普通股代號 2330，區別 NYSE 的 TSM 存託憑證。未保存公司財報全文或財務數據。
- **時間**：來源日期是交易日，不是即時報價，也沒有精確發布時間；沿用成功取得回應後的觀測時間作為可得性上界。研究截止時間在採集之後建立，不能倒填歷史時間。

結論是針對上述資料集及用途的有依據使用判斷，不是對所有來源或所有未來條款作法律保證。若官方條款或資料契約改變，重新查核，無法確認則封鎖。

## 能力限制
